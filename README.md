# Sticky notes

A simple web app where you can add, edit, and delete notes.

## Features
- Add, edit, and delete notes
- Customize the theme/color of each note
- Drag and drop notes for easy organization
- Persistent note storage using PostgreSQL

## Technologies Used

### Frontend
- Next.js
- Tailwind CSS

### Backend
- Node.js and Express.js
- PostgreSQL

## Getting started

### Prerequisites

Make sure you have installed:
- Node.js
- PostgreSQL

### Installation 

#### 1- Clone the repository:

```bash
git clone https://github.com/anusair/sticky-notes.git
```

#### 2- Navigate to the project directory

```bash
cd Sticky-notes
```

#### 3- Install dependencies 

- You have two directories which are:
  1- client -> Frontend
  2- server -> Backend

```bash
npm install 
```

- Since I'm using JS in both use this command for both directories

#### 4- Start the development server

- Next.js
```bash
npm run dev
```

- Node.js
```bash
node server.js
```

## How it works
- Click the + button to create a new note
- Drag notes to organize them
- Customize each note's appearance using themes/colors
